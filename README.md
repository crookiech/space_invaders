## В ветке UART представлена реализация контроллера команд, передаваемых по uart
### Выполнил студент группы 8В32 Тимохина Валерия

В ROM.mif хранятся следующие команды: res1024, res640, res1360 - для переключения разрешения, speed1-speed9 - для переключения скоростей.
При вводе команды, которая имеется в ROM, в терминал выводится сообщение "OK", иначе - "Unknown command".


## В ветке HDMI представлена реализация вывода изображения через HDMI интерфейс
вывода изображения через HDMI интерфейс включающий конфигурацию ADV7513, управление по I2C и обработку HPD (Hot Plug Detect), генерацию видеосигналов для HDMI выхода.
### Выполнил студент группы 8В32 Гекк Софья
Реализован вывод изображения на монитор через HDMI интерфейс, включающий:

- **Конфигурацию ADV7513** – инициализация HDMI передатчика с поддержкой трёх разрешений (640×480, 1024×768, 1360×768)
- **Управление по I2C** – передача конфигурационных данных на ADV7513
- **Обработку HPD (Hot Plug Detect)** – обнаружение подключения/отключения монитора
- **Генерацию синхросигналов** – формирование HSync, VSync, DE и координат пикселей (pixel_x, pixel_y) в соответствии с выбранным разрешением

**Принцип работы:**
1. При подаче питания или смене разрешения выполняется инициализация ADV7513
2. Через I2C интерфейс отправляются настройки (базовые + специфичные для выбранного разрешения)
3. Формируются видеосигналы в соответствии с выбранным разрешением и текущие координаты пикселя
4. Игровая логика и отрисовка используют координаты для формирования RGB сигналов
5. Все сигналы подаются на ADV7513 и выводятся на монитор через HDMI

## В ветке HDMI также представлена реализация игровой логики и системы отрисовки
### Выполнил студент группы 8В32 Романчук Софья
**Реализованные компоненты:**
- Игровой конечный автомат (меню, игра, пауза, конец игры)
- Отрисовка спрайтов (игрок, враги, пули, стены)
- Управление через кнопки на ПЛИС
- Система коллизий и подсчёта очков

**Игровая механика:**
- Игрок управляет пушкой в нижней части экрана
- Враги двигаются змейкой сверху вниз
- При попадании враг уничтожается, игрок получает очки
- Игра заканчивается при столкновении с врагом или достижении края экрана
